# 全国学力調査を読み解く2026

公立中学校3年生について、2024〜2026年度の国立教育政策研究所の
教科概況・生徒質問紙集計を47都道府県分表示する静的ページ。
`index.html`、`data.js`、`app.js`だけで動作し、外部のグラフサービスは使用しない。

## 収集と再生成

Pythonの`openpyxl`を使用（原資料の読み取りのみ）。
リポジトリのルートから以下を実行する。

```sh
python3 education-data/tools/collect.py
python3 education-data/tools/extract.py
```

取得先は公式都道府県一覧からたどる。2024年度は国立国会図書館WARPの
保存資料を利用。原資料は`.source-cache/`に保存しGit管理しない。
`sources.json`に282ファイルのURL、年度、県コード、SHA-256を記録する。
資料更新時はキャッシュを退避・削除して再取得し、差分を確認する。
今回の確認日は2026-10-14。

人口比較の元データは`tools/population.json`。
2020年国勢調査「結果の概要」表Ⅳ－2－1（33ページ）の総人口。
長野県との差が±20％以内の県を抽出。最新人口の比較ではない。

## 数値の仕様

「全教科合計・一覧」は当該年度の全実施教科を横並びに表示。
国語正答率＋数学正答率を各100点相当・200点相当の参考合計として計算する。
2024年度のみ実施全教科に相当。2025・2026年度は理科・英語のIRTと
正答率を合算できないため、全教科合計を「算出不可」とし、国語＋数学の
部分合計を別表示。公式総得点、個人の平均総点、正答数合計ではない。
英語4技能と3技能を別教科として二重に足さない。年度間の総点比較は提供しない。

- 教科概況の国語・数学：各シートG8（県）、G9（全国）。
- 英語・理科：C19（県の公表幅）、C20（全国の公表値）。
  英語4技能、3技能は別尺度・別対象。平均幅を点推定に変換しない。
- IRTバンド：AA8:AE8（県）、AA9:AE9（全国）。
- 質問紙：質問文で対応付けし、該当設問の人数行、次行の県の割合、
  3行後の全国の割合を読み取る。セル位置・設問番号を各値に保存。
- 18指標を選定。年度ごとに公開されていない指標は存在させない。
- 肯定回答は選択肢1・2の公表割合を合計。平日の1時間以上は1〜3。
  ICT週3回以上は2024年度1・2、2025・2026年度1〜3。
  丸め前の合計率を推定せず、無回答・その他を分母から除かない。
- 全国値は公式表の値を使用。県平均の単純平均から全国値を作らない。
- 全国・県は国語・数学・3技能英語・理科で公立。
  4技能英語の全国は国公私立の当日4技能実施抽出校、県は公立の
  当日・期間内実施合算。異なる集計対象のため全国との差を表示しない。

## 検算

抽出時に47県＋全国、教科数、同年度の全国値一致、数値型を確認。
県の質問紙割合を人数÷公表母数×100と照合（小数1桁の丸め許容0.051pt）。
IRTバンドの合計が100％から0.4pt未満の範囲に収まることを確認。
選択した回答割合の人数照合など5,264件を実施。掲載レコード数は2,784。
公開集計の転記・算術検算であり、個票の再集計ではない。

相関は47県を等しい重みで扱うPearson相関。全国平均を除外。
同年度の国語または数学正答率と質問紙回答率を用いる。
回帰直線は最小二乗法。IRT平均の幅を中点に置換して計算しない。
2026年度の数学好きと数学はr=0.289（小数3桁）、
平日1時間以上の学習と数学はr=0.379。独立にNumPyで照合。

## 比較の限界・未収録

理科・社会・英語は全年度の教科選択に表示する。
未実施年度は「調査対象外」と理由を表示し、理科・英語は実施年度へ移るボタンを提供。
社会はこの全国調査の教科に含まれないため、実数値は掲載しない。

国語・数学の問題は年度で異なり、正答率や全国との差は等化された
能力尺度ではない。年度間を同一個人の成長として扱わない。
質問紙は自己申告。番号変更、ICT頻度の選択肢変更、調査条件の違いに注意。
丸め後の公表割合の合計は人数から算出する合計割合と異なり得る。
相関から因果を主張せず、地域の相関を個人の相関へ移し替えない。
家庭背景や塾などの交絡調整、統計的有意差の判定は未実施。

小学校、指定都市単独、学校質問紙、問題別正答率、非公開・ランダム方式で
集計対象外の設問は未収録。生徒質問紙の全設問を掲載したものではない。
