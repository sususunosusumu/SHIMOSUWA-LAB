# 下諏訪向陽高校 通学ナビ V1

公開先: https://sususunosusumu.github.io/SHIMOSUWA-LAB/commute/

ビルド不要の GitHub Pages 用 HTML/CSS/JavaScript。トップページに入口を追加。

## 使い方

1. 出発・目的地と利用できる交通手段を選び「移動方法を比較」。現在時刻が初期値、日時は日本時間で変更可能。
2. 電車一覧の時刻をタップすると学校〜駅の各手段の出発期限を表示。乗換余裕は初期5分。
3. 自宅・地図ポイント設定を開き、地図をクリックするか緯度経度を入力。任意地点に設定／自宅として保存後、地点一覧から選択。
4. 現在地選択はGPSの許可が必要。拒否・取得失敗時は地図指定が可能。
5. 自宅と保存設定は消去ボタンで削除可能。

## データ・照合（2026-10-12）

- あざみ号: 既存 `GTFS/ccby4_azami_all_routes_gtfs.zip` の武居線8便を再利用（Shimosuwa Lab / CC BY 4.0）。公式武居線画像の学校、駅発、駅着を全8便目視照合。5便は毎日、6便は土日祝のみ、その他は平日のみに修正。未検証の他路線と元GTFSの不正確な座標は利用しない。
- バス原典: https://www.town.shimosuwa.lg.jp/www/contents/1001000000461/simple/b.jpg
- 公式案内: https://www.town.shimosuwa.lg.jp/www/contents/1001000000461/index.html （閲覧時は2026年2月16日改正版）。10月改正の案と確定情報を混同せず、確認済み月のみ検索。確認期限は10月31日。
- 鉄道: 既存 `train/schedule.json` の116レコードを起点に、各JR東日本2026年10月版公式ページの全停車時刻と運転日カレンダーを再取得。入出両方向と周辺駅間の乗車を計算。原典URLは各レコードに保持。サンプル列車なし。下諏訪に停まる収録列車のみで、下諏訪非停車列車や鉄道の乗り継ぎは対象外。
- 祝日: 内閣府 https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv の祝日を利用。
- 地点: 学校・駅は既存GIS停留所データを使用。周辺駅は概略座標。自宅の最寄駅は収録6駅から直線距離で選択するため、道路経路上の最適駅を保証しない。
- 移動時間: 学校〜駅は約2km（町の公共交通計画記載）、徒歩4km/h・小走り7km/h・自転車12km/h、学校方向に1.25倍。その他は直線距離×1.35。道路探索・標高解析を実施していない概算。坂道・冬季・通行止め・自転車通学可否は利用者が確認する。
- バスと徒歩/小走りの複合は学校・駅の停留所周辺1.5kmまで。電車の前後移動は徒歩などと組み合わせ、電車への自転車持込みを仮定しない。駅から先の自転車は対象外。
- 期限後は公共交通候補を非表示。徒歩等の概算は利用可能。遅延・運休・臨時変更は反映しない。更新時には公式時刻と運転日を再照合し `validUntil` を更新する。

## プライバシー

自宅座標と交通手段設定はブラウザのlocalStorageのみ。検索は端末内。GPS座標は保存しない。地図ポイントはメモリのみ。分析・追跡コードなし。LeafletはCDNから読込。地図タイルは「地図を開く」操作後のみ取得し、OSMにIPと表示範囲が送信される。Google Maps経路リンクを開いた場合は出発・目的地がGoogleに送信される。
