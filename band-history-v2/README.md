# 諏訪地区の中学校・長野県の高校の吹奏楽史 Ver.2

公開先：https://sususunosusumu.github.io/SHIMOSUWA-LAB/band-history-v2/

HTML・CSS・JavaScript・JSONだけで動作するGitHub Pages用の静的サイトです。Ver.1のファイルは変更しません。外部ライブラリ、解析サービス、外部フォントは使用していません。

## 操作

初期表示は下諏訪町立下諏訪中学校。学校別・指揮者別・曲目別・大会別・編成別・統計の6表示を切り替えます。「対象部門」で諏訪地区の中学生部門と長野県全体の高校部門を切り替えます。A・B・C編成／大・小編成も専用項目で絞り込めます。学校・指揮者・曲目・大会の名称から関連する記録へ移動できます。年度範囲、作曲者、曲目、大会、賞、編成、人数、確認状況で絞り込みます。年表と表の切替、詳細と複数出典表示、CSV保存、検索条件付きURL、7種類の統計グラフを備えています。

別の視点へ切り替えるタブと関連リンクは検索条件をリセットします。学校別タブは中学生部門で下諏訪中学校、高校部門で諏訪清陵高校に戻ります。「条件をリセット」は選択部門の全校を対象にします。統計はその時点の検索条件を反映します。

## 現在の収録範囲（2026-10-09）

- 諏訪地区の中学校は現行17校・旧校1校。高校部門は公立・私立・旧校・資料上の名称と合同団体を登録。
- 2010〜2026年度の公式HTML大会記録を中心に7,807件（辞退・欠場等も大会履歴として含む）。
- 長野県吹奏楽連盟の地区・ブロック・県大会、確認できた中部日本大会。2026年度のアンコンなど未来の未開催結果は収録していません。
- 指揮者438識別項目（学校ごとに分け、同じ表記は検索時にまとめて表示。人物数を意味しません）、曲目4,333項目（抜粋・編曲の違いを維持）、大会301項目、出典314件。
- 学校一覧は長野県教育委員会「公立中学校一覧」を参照。県立諏訪清陵高校附属中学校も対象に含めています。

2000〜2009年度の旧システム記録、東海・全国大会、PDFだけの記録、学校・自治体資料の網羅的調査は未完了です。2020年度の開催状況は各大会別に追加確認が必要です。未登録・未調査・項目未確認を「不参加」「受賞なし」に変換しません。

## データ構造と更新方法

`data.json` の学校・指揮者・曲目・大会・演奏記録・出典をIDで関連付けます。各配列のIDは重複させず、追加・修正時も既存IDを維持してください。

| 配列 | 主なフィールド |
| --- | --- |
| schools | id, name, officialName, municipality, level, isJoint, memberSchoolIds, aliases, nameHistory, relations, sourceIds |
| conductors | id, name, normalizedName, schoolId, aliases, identityStatus, appointments, sourceIds |
| works | id, title, composer, arranger, aliases, sourceIds |
| events | id, year, name, family, level, stage, label, date, venue, sourceIds |
| performances | id, schoolId, eventId, year, level, division, divisionRaw, conductorId, pieces, award, recommendation, ensemble, ensembleCategory, size, sourceIds, status, performed, participationStatus, rawRow, note |
| sources | id, title, url, publisher, checkedAt |
| coverage | year, level, family, status, recordCount, note |
| eventStatuses | 大会中止・未開催などを出典付きで将来追加するための領域 |

1. 公開資料を確認し、`sources` に出典を登録します。同じ演奏記録に複数の出典IDを付けられます。
2. 学校・曲目・指揮者・大会を必要に応じて追加します。指揮者のIDは学校別に分けます。同じ表記の指揮者は画面上の検索結果をまとめますが、記録の学校は保持し、同一人物と判断しません。
3. `performances` に実演奏の記録を追加します。`year` は大会年度、`date` は開催日です。異なる大会段階は別記録にします。
4. 不明なID・開催日・会場・編曲者・人数は `null`。推薦表示がない場合の初期値も `null` です。空白を「なし」と解釈しません。編曲者がnullなら「編曲なし」ではなく「未確認」を表示します。
5. 課題曲番号だけ確認できる場合は `pieces` の `workId: null`, `role: "課題曲"`, `raw: "Ⅰ"` としてください。曲名を公式課題曲資料で確認できたら曲目IDを登録します。
6. `status` は記録全体の「確認済み」「一部確認」「未確認」。欠落項目がある場合は「一部確認」、`note` に確認できた範囲を記載してください。
7. `coverage` と `updatedAt` を更新し、`python3 band-history-v2/validate.py` を実行します。
8. このフォルダーを公開ブランチに反映するとGitHub Pagesで更新されます。インストール・ビルドは不要です。

学校の旧名称は `nameHistory`、別校の統合関係は `relations` に出典付きで登録します。統合と単なる改称は区別してください。確認できていない学校沿革や在籍期間は空配列にしています。指揮者の `appointments` は大会記録とは独立し、出典のある勤務期間だけ登録できます。現行UIは大会指揮年度を表示し、在籍期間の可視化は将来拡張です。

## 集計の定義

- 演奏回数：大会段階ごとの演奏記録数。辞退・欠場98件と実演未確認2件は実演統計から除外し、受賞・演奏結果を確認した7,837件を集計対象にします。同曲の地区・県演奏は2件。
- 代表推薦：公式表の「代表」を確認した記録数。上位大会実出場や異なる年度の進出回数とは別。
- 年度別参加学校数：登録済み記録内の学校・合同団体IDの重複を除いた数。辞退・欠場・実演未確認を除外します。
- 指揮者の検索：同じ表記の記録をまとめて表示します。結果は学校別のまま表示し、同一人物かどうかは未確認です。指揮者統計も同じ表記ごとに集計します。
- 編成・人数：資料の編成表記に基づき整理。空白人数は除外。
- 中部日本の賞（優勝・準優勝・優秀・努力など）は原表記を保持し、金銀銅へ換算しません。

合同参加は独立した団体IDにし、確認できた構成校IDをmemberSchoolIdsに記載します。学校を選ぶと確認できる合同記録も表示します。旧校・改称・統合の同一性は出典確認後に追加できます。

A・B編成は資料の部門見出しから登録します。A/Cなど複数編成のページで区分境界が明記されていない行は「A/C（未区別）」を保持し、課題曲の有無から推測で埋めません。原表記divisionRawも残します。アンサンブル団体名末尾のA/Bは同校内グループの識別であり、コンクールのA/B編成として扱いません。

現時点で曲名の異体字・翻訳名、作曲者のカタカナ/英語表記などはすべて統一できていません。原表記を残し、空白・全角/半角を整えた照合を行っています。編曲者・抜粋が異なるものは別項目にします。

## ローカルで確認

リポジトリのルートで Python 3.7以上の `python3 -m http.server 8765` を実行し、`http://localhost:8765/band-history-v2/` を開きます。`file://` で直接開くとJSONを取得できないブラウザーがあります。
