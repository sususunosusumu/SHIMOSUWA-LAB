# JR時刻表 V2 開発版

既存の `GTFS-TRAIN/index.html` とZIPは変更せず、ここだけに追加する静的Webアプリ。

## 実装

- 松本を初期駅とする時刻表、駅別タイムライン、駅間ダイヤの切替。
- 普通／あずさ／貨物／その他（快速・他特急）の独立フィルター。
- 日本時間での運転日・現在時刻、松本方面／東京方面、参考曜日データの手動選択。
- 岡谷〜茅野、塩尻〜富士見、松本〜小淵沢、みどり湖／辰野経路。
- 時間範囲、横倍率、駅間の高さ、選択列車の強調、詳細。
- ダイヤで1分／300msの時間再生、一時停止、スライダー、現在時刻へ。
- 駅・モード・条件の保存（運転日は毎回日本の当日）。
- 読込失敗、空結果、収録期間外、不正な時間範囲の明示。

## 共通データ

`build_data.py` を実行すると既存ZIPから `data.json` を再生成する。依存はPython標準ライブラリのみ。3表示とも `model.js` のカレンダー・分類・選別ロジックを使う。

列車記録はGTFS trip IDのまま保持。同じ列車番号を独自判断で合併せず、複数記録を明示する。時刻を推測・補完しない。駅座標は仮値なので出力にも含めない。停車駅は `[駅名, 到着時刻, 発車時刻]`。

元ZIP SHA256: `d996e7ae9987d9cc7e6067d676bb60018c70b334d5568d6b6f750b657019e953`

出典・調査日・制約は `sources.json` に集約。公式時刻表を新しく取り込む場合は、原資料URL、対象月、適用日、取得日、各列車の運転日・例外を記録し、照合後に確認状態を更新する。

## 2026-10-12の検証

JR東日本の下諏訪駅公式ページ、および `2610/timetable-v/223d2p.html` の2026年10月版中央本線下り土休日時刻表を閲覧できた。列車番号、時刻、個別運転日・時刻変更の記載がある。月版の存在は10月一斉改正の証拠ではない。中央本線・篠ノ井線の2026年10月一斉改正と正確な適用日は確認できず、未確認とした。JR東日本とJR貨物の公式資料で確認した改正日は2026-03-14。

公式HTMLを取得する可能性は確認できたが、全列車の自動抽出・10月版照合は未実施。ブラウザからの直接取得はCORS・構造変更の検証が別途必要。現段階では既存2026年5月版を参考データとして使用する。

JR貨物は公式コンテナ時刻表への案内を公開している。しかし今回、下諏訪を含む各駅の貨物通過時刻・運転日を確認できなかった。貨物記録は0件で、フィルター選択時にも生成しない。

## 未確認・欠損

祝日設定（元ZIPの calendar_dates は空）、臨時運転、特定日の変更、通過駅・通過時刻、実際の始発終着、停車時間、最新時刻との差分、リアルタイム位置は未確認／未実装。ダイヤは等間隔の駅順。両経路を初期表示とし、経路を個別に絞ることもできる。収録された2駅以上の発時刻を線で結ぶ。位置追跡は実装しない。

始発・終着欄は実際の端点を断定せず「未確認」とし、全収録区間の端を併記。件数は記録件数であり実本数ではない。robots は noindex にして開発版を検索結果へ出さない。

## 確認方法

`node test.cjs` で日付・曜日、例外日、期間外、分類、経路、24時超時刻、貨物0件、全時刻の順序を検証する。ローカルHTTPサーバーで `index.html` を開く。外部JavaScript依存なし。

動作確認：Chromeで3モード、列車選択と詳細、ダイヤへの移動、倍率、時間再生、独立フィルター、貨物のみ0件、駅の保存、期間外、時間範囲エラー、390px幅の画面を確認済み。既存ページの差分は0。

2026-10-12 表示調整：初期駅は松本、初期範囲は松本〜小淵沢。旧設定を保存済みのブラウザも一度だけ駅・範囲を新しい初期値へ移行。ダイヤの時刻目盛を縦向きにし、上部の余白を拡大。

表示改訂：タイムラインは選択駅から先の停車駅の着・発を横並びで表示。時刻表の行高を縮小して時刻を種別・経路の色で表示。ダイヤの横幅を拡大し、線上にクリック可能な列車番号を配置。辰野経由は普通を青緑、あずさを赤紫と破線で区別する。分類は収録停車駅のみから判定し、辰野経由のあずさを新規に作らない。

追加改訂：ダイヤの列車番号を縦向きにし、選択駅の交点に収録発時刻を表示。タイムラインは全収録停車駅を保持し、初期スクロールを選択駅へ合わせる。前の駅は横に戻して参照できる。第4モード「乗り継ぎビュー」は横軸に駅、色の横線に列車、破線に待ち時間を表示。直通・乗換1回、最低待ち時間3/5/10/15分、待ち上限120分、最大30件。ホーム移動・実運転・運転日・運賃・特急券は未検証。候補がない場合に運行なしとは断定しない。

第5モード「スケジュール探索」：横軸＝共通の時刻、縦軸＝駅。第4モードと同じ直通・乗換1回の候補を斜線で重ねる。停車は着〜発を同じ駅で横に結び、乗換待ち時間は破線のバーとして実分数で描画。前後の便を比較し、候補選択で経路を強調。Googleのサービス名・ロゴは使用せず、提供された画面の説明を参考に独自実装。

乗り継ぎビューの省スペース改訂：独立した図と大きな時刻見出しを廃止し、駅列を共有する一つの表へ変更。1行約38px。到着駅は任意、指定なしでは収録範囲内の終点候補を集約して最大60件を表示。選択駅を初期スクロールの左端に合わせ、前後の収録駅も横スクロールで参照できる。区間外時刻は薄く表示。列車詳細は普段非表示で、番号・時刻のクリックで開閉する。
